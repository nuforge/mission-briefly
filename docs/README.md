# Architectural Decision Records (ADR)

This directory contains architectural decision records for the Mission Briefly project.

## Format

Each ADR follows this structure:

- **Status**: Proposed, Accepted, Deprecated, Superseded
- **Context**: The situation that led to this decision
- **Decision**: The change we're proposing or have agreed to
- **Consequences**: The positive and negative outcomes of this decision

## Template

```markdown
# ADR-XXX: [Title]

## Status

[Proposed | Accepted | Deprecated | Superseded by ADR-XXX]

## Context

[Describe the situation that led to this decision]

## Decision

[Describe the change we're proposing or have agreed to]

## Consequences

### Positive

- [List positive outcomes]

### Negative

- [List negative outcomes or tradeoffs]

## Notes

[Any additional information, alternatives considered, etc.]
```
